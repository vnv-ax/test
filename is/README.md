# Исходники «Экономно»

Это Next.js-приложение (статическая сборка), из которой собирается папка `app` для `.exe`-оболочки.

## Быстрый старт

```bash
bun install      # один раз: поставить зависимости
bun run dev      # разработка на http://localhost:3000
bun run build    # production-сборка в папку out
```

Готовую сборку `out` нужно скопировать в корневую `app`:

```powershell
robocopy .\out ..\app /MIR
```

> Исходники — только эта папка. Корневая `app` — уже собранный сайт, её не редактируют вручную: при следующей сборке изменения затрутся.

## Что НЕ хранится в исходниках

Эти папки и файлы создаются автоматически и удалены при очистке:

- `node_modules/` — зависимости, ставятся через `bun install`;
- `.next/` — кэш разработки и сборки;
- `out/` — результат `bun run build`;
- `tsconfig.tsbuildinfo` — служебный кэш TypeScript;
- корневая `app/` — готовая собранная версия для `.exe`;
- корневые `Экономно.exe`, `runtime-data/`, `data/` — оболочка и пользовательские данные.

## Правило правок

1. Меняем только файлы в `izhodnik/src` (и при необходимости `public`).
2. Проверяем: `bun run dev`.
3. Собираем: `bun run build`.
4. Копируем `izhodnik/out` в корневую `app`.
5. Пользовательские данные в `runtime-data` и `data` при этом не затрагиваются.
