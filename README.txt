* data\замечательно.vault      — основной файл

Кнопка «Экспорт» на главном экране сохраняет JSON в data\exports
(или в выбранную папку). На другом устройстве — «Импорт» и выбрать файл.
Можно выгрузить как все листы, так и отдельный лист: клик правой по пустому.
Файлы экспорта НЕ зашифрованы — храните их осознанно.


Офлайн и приватность
+===================================================================================+
* Приложение не имеет выхода в интернет: все сетевые запросы блокируются.
* Данные и кэш WebView2 хранятся только в этой папке (не в AppData).
* Дополнительно можно запретить exe в брандмауэре Windows
  (правила «исходящие» и «входящие» для Замечательно.exe).
+===================================================================================+


Если WebView2 не установлен
+===================================================================================+
Windows 10/11 обычно уже содержит Microsoft Edge WebView2 Runtime.
Для полностью офлайн-компьютера скачайте «Fixed Version» WebView2 Runtime
и положите папку с msedgewebview2.exe в WebView2Runtime\ рядом с Замечательно.exe.
