# МИШКА — остров ягод и рыбалки

Милая 3D-игра для планшета и телефона (в том числе старых iPhone) на Three.js.
Медвежонок гуляет по красочному острову: ищет ягоды на кустах, ловит рыбу в пруду,
наедается и выполняет весёлые задания.

![скриншот](https://user-images.githubusercontent.com/_placeholder.png)

## Возможности

- Управление виртуальным джойстиком (слева) + контекстная кнопка действия (справа).
  На компьютере: WASD / стрелки и E / Space / Enter.
- 6 анимаций медведя, запечённых процедурно: idle, walk, eat, fish_cast, fish_catch, cheer.
- Сбор ягод с кустов (кусты отрастают через ~25 с), рыбалка с мини-игрой на реакцию
  («ТЯНИ!» в момент поклёвки), шкала сытости и цепочка заданий.
- Прогресс сохраняется в localStorage.
- Звук на Web Audio (синтез, без аудиофайлов), кнопка выключения звука.

## Запуск локально

Игра — полностью статичные файлы. Нужен любой HTTP-сервер (не file://):

```bash
cd bear-game
python3 -m http.server 8080
# открой http://localhost:8080
```

## Размещение на GitHub Pages

1. Создай репозиторий на GitHub (например `bear-game`).
2. Загрузи туда **содержимое** папки `bear-game` (index.html, js/, models/) —
   через веб-интерфейс или:
   ```bash
   git init
   git add .
   git commit -m "Мишка: 3D-игра"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/bear-game.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source:
   Deploy from a branch → Branch: main → Folder: / (root) → Save**.
4. Через минуту игра будет доступна по адресу
   `https://<твой-логин>.github.io/bear-game/`.

Подойдёт и любой другой статический хостинг (Netlify, Vercel, Cloudflare Pages) —
просто укажи папку `bear-game` как корень сайта.

## Почему это работает на старых iPhone

- **Three.js r147 (UMD-сборки)** — последняя ветка с `examples/js` и с поддержкой
  WebGL1-fallback: на iOS 12–14 (WebGL1) и iOS 15+ (WebGL2) работает один и тот же код.
- Никаких import maps, модулей и опциональных цепочек `?.` — синтаксис совместим с iOS 10+.
- Модель сжата из 26 МБ до **3.3 МБ**: текстуры 2048→1024 (JPEG/PNG), нормал-мапы
  удалены, невидимый ошейник вырезан, веса скиннинга uint8, индексы uint16.
- Мировая геометрия слита в несколько мешей: весь мир ≈ **35 draw call'ов** и ~45k треугольников.
- Без shadow maps (пятна-блобы), с туманом и адаптивным pixelRatio
  (автоматически снижается при просадке FPS), touch-action: none, safe-area отступы.

## Структура

```
bear-game/
├── index.html            — разметка, HUD, стили
├── models/bear.glb       — оптимизированная модель медведя (3.3 МБ)
└── js/
    ├── game.js           — вся игра (сцена, механики, UI)
    ├── anims.json        — 6 запечённых анимационных клипов (127 КБ)
    └── lib/
        ├── three.min.js            — Three.js r147 (UMD)
        ├── GLTFLoader.js           — загрузчик GLB (UMD)
        └── BufferGeometryUtils.js  — слияние геометрий (UMD)
```

## Тонкая настройка

- Скорость медведя, радиус острова, пруд, константы геймплея — в начале `js/game.js`
  (блок `constants`: `WORLD_R`, `POND`, `BEAR_SPEED`, `BEAR_SCALE` и палитра `COL`).
- Анимации — файл `js/anims.json`: клипы собраны процедурно (ФК по скелету с
  мировыми осями). Можно перегенерировать или править значения кватернионов вручную.
- Задания — массив `QUESTS` в `game.js`.
